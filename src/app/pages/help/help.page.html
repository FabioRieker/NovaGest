1. Autenticación y Control de Acceso por Roles (RBAC)

El sistema implementa Guards de Enrutamiento (authGuard y roleGuard) que protegen las vistas privadas. Las rutas administrativas como el Cuadro de Mando o la creación de productos están estrictamente restringidas al rol admin.

Al iniciar sesión, se genera un token de sesión JWT simulado que se almacena de forma segura en el almacenamiento local y se inyecta automáticamente mediante un interceptor HTTP en las peticiones salientes.

2. Gestión de Catálogo y Componente Tabla Avanzada

La vista de inventario utiliza el componente agnóstico reutilizable <app-data-table>, el cual ofrece:

  • Búsqueda en tiempo real: Filtrado instantáneo por SKU, nombre o proveedor con debounce.
  • Ordenación por columnas: Haga clic en la cabecera de cualquier columna (o presione Enter con teclado) para alternar orden ascendente o descendente.
  • Paginación configurable: Control de registros por página y botones accesibles de avance/retroceso.
  • Operaciones CRUD: Creación, modificación y eliminación con confirmación modal accesible.
 3. Formularios Reactivos y Validación Asíncrona

En el formulario de alta de productos, el campo Código SKU cuenta con un validador asíncrono (skuAsyncValidator). Al escribir un código, el sistema consulta en segundo plano a la API SQL con un spinner visual y anuncia el estado mediante aria-live="polite". Si el SKU ya existe, el botón de guardar se bloquea automáticamente evitando duplicados.

4. Cuadro de Mando e Informes en PDF y CSV

El Cuadro de Mando integra gráficos interactivos renderizados con Chart.js y widgets KPI estadísticos (<app-stat-widget>). Se sincroniza de forma concurrente (forkJoin) con la API SQL de Supabase (PostgreSQL) y el canal WebSocket de Supabase Realtime.

La exportación permite generar informes en PDF formal tabulado (mediante jspdf-autotable) o en CSV compatible con Excel con codificación UTF-8 BOM.

5. Guía de Accesibilidad y Navegación por Teclado

La interfaz ha sido diseñada conforme a las pautas de accesibilidad WCAG 2.1 AA / AAA:

Tecla Acción
Tab Desplaza el foco al siguiente elemento interactivo (con anillo de enfoque visible).
Shift + Tab Desplaza el foco al elemento interactivo anterior.
Enter / Espacio Activa botones, enlaces o alternar ordenación en las cabeceras de la tabla.
Esc Cierra menús desplegables y modales de confirmación.
